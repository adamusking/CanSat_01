# CanSat_01

Welcome to the **CanSat_01** repository! This project is developed by the **Adlerka Space Agency**, a student-led team dedicated to advancing space technology through hands-on projects. Our mission is to design, build, and test a CanSat—a simulated satellite contained within a standard 330ml can—to perform scientific experiments and demonstrate satellite technologies.

For more information about our team, visit our [About page](https://adlerkaspaceagency.eu/about.html#).

---

## 🚀 Project Overview

The **CanSat_01** project aims to:

- Integrate essential satellite subsystems such as power, sensors, and communication into a compact form factor.
- Conduct scientific experiments during descent after being launched to an altitude of approximately 1 kilometer.
- Ensure safe landing and data retrieval for analysis.

This project provides a practical introduction to satellite engineering and space mission operations.

---

## Repository Structure

The repository is organized as follows:

- **`cansat_mains/`** – Test main scripts for experimenting with CanSat functionalities    
- **`communication/`** – Handles data transmission and reception between the CanSat and the ground station.  
- **`include/`** – Header files for various modules and configurations.  
- **`lib/`** – Libraries for sensor interfacing and other utilities.  
- **`src/`** – Source files implementing the CanSat functionalities.  
- **`test_code/`** – Test scripts and code for validating individual components.  
- **`.vscode/`** – Visual Studio Code workspace settings.  
- **`.gitignore`** – Specifies files and directories to be ignored by Git.  
- **`platformio.ini`** – PlatformIO project configuration file.  
- **`README.md`** – This document.

## Prerequisites

To work with this project, ensure you have the following installed:

- [PlatformIO](https://platformio.org/) – A cross-platform IDE for embedded development.  
- [Visual Studio Code](https://code.visualstudio.com/) – A lightweight code editor.  

---

## Mission Objectives

The primary mission objectives of CanSat_01 are:

- **`Data Collection/`**  – Measure and transmit environmental parameters such as temperature, pressure, and altitude
- **`Safe Landing/`**  – Ensure the CanSat lands within a designated area using a parachute system
- **`Data Retrieval/`**  – Retrieve the collected data for analysis and reporting
