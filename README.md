# CanSat_01

Welcome to the **CanSat_01** repository! This project is developed by the **Adlerka Space Agency**, a student-led team dedicated to advancing space technology through hands-on projects. Our mission is to design, build, and test a CanSat—a simulated satellite contained within a standard 330ml can—to perform scientific experiments and demonstrate satellite technologies.

For more information about our team, visit our [About Us page](https://adlerkaspaceagency.eu/about.html#).

---

## Project Overview

The **CanSat_01** project is an initiative by the **Adlerka Space Agency**, a student-led team from Adlerka Secondary Vocational School, participating in this year's CanSat competition. Our mission is to design, build, and deploy a CanSat—a simulated satellite contained within a standard 330ml can—to conduct scientific experiments and demonstrate satellite technologies.

### Mission Objectives

- **Air Quality Monitoring** – Measure concentrations of **carbon dioxide (CO₂)** and **sulfur dioxide (SO₂)** to assess air pollution levels. These gases contribute to environmental issues such as the greenhouse effect and acid rain.  
- **Data Collection** – Capture environmental data during the CanSat's descent from an altitude of approximately 1 kilometer, providing insights into atmospheric conditions.  
- **Safe Landing** – Implement a parachute system to ensure the CanSat lands within a designated area, facilitating easy retrieval.  
- **Data Retrieval and Analysis** – Retrieve the collected data for post-mission analysis, aiming to provide actionable insights into air quality and environmental health.  

This project offers a practical introduction to satellite engineering and space mission operations while contributing valuable data to understanding air pollution.

## Repository Structure

The repository is organized as follows:

- **`cansat_mains/`** – Test main scripts for experimenting with CanSat functionalities    
- **`communication/`** – Handles data transmission and reception between the CanSat and the ground station.  
- **`include/`** – Header files for various modules and configurations.  
- **`lib/`** – Libraries for sensor interfacing and other utilities.  
- **`src/`** – Source files implementing the CanSat functionalities.  
- **`test_code/`** – Test scripts and code for validating individual components.  
- **`.vscode/`** – Visual Studio Code workspace settings.  
- **`.gitignore`** – Specifies files and directories to be ignored by Git.  
- **`platformio.ini`** – PlatformIO project configuration file.  
- **`README.md`** – This document.
